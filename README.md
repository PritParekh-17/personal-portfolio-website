# Personal Portfolio Website

A personal portfolio website built using **HTML5** and **CSS3** to present my profile, education, activities, interests, values, and contact information in a simple multi-page format.

## Live Demo

* **Website:** https://personal-portfolio-website-sandy-seven.vercel.app/
* **Repository:** https://github.com/PritParekh-17/personal-portfolio-website

## Overview

This project is a lightweight static portfolio website created to showcase my personal profile and background on the web. It is designed using only HTML and CSS, without any frameworks or build tools, making it easy to understand, maintain, and deploy.

The website contains multiple pages for different sections such as education, hobbies, experience, personal values, feedback, and contact details.

## Features

* Multi-page portfolio website
* Clean and simple front-end design
* Dedicated pages for education, hobbies, experience, and personal values
* Contact and feedback pages
* Fully static website with no backend dependency
* Easy deployment on GitHub Pages or Vercel

## Tech Stack

## Run Locally

Since this is a static website, no installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/PritParekh-17/personal-portfolio-website.git
   ```
2. Open the project folder.
3. Run `index.html` in your browser.

## Deployment

This project can be deployed directly as a static site.

### GitHub Pages

1. Push the project to GitHub.
2. Open **Settings → Pages**.
3. Select the **main** branch and root folder.
4. Save to publish the site.

### Vercel

1. Import the repository into Vercel.
2. Keep the framework preset as **Other** / static site.
3. Deploy the project.
